# Complete-page candidate-group data contract

`scripts/train_s2tpo_actor.py` consumes one JSON object per line. Each object
represents `W` complete pages independently generated by the frozen TIGER
policy for the same request context. It does not represent `W` replacements
for one fixed page slot.

Required fields:

| Field | Shape | Meaning |
|---|---:|---|
| `schema_version` | scalar | Must equal `s2tpo_complete_page_group_v1` |
| `context_input_ids` | `[H]` | Tokenized TIGER encoder context |
| `context_attention_mask` | `[H]` | Optional context mask; defaults to ones |
| `candidate_sids` | `[W,N,L]` | `W` complete pages, each containing `N` complete item SIDs |
| `critic_member_path_values` | `[W,N,L+1,C]` | Raw values from `C` critics along every masked-to-complete item path |

This is the only actor-input schema. A context occupies one JSONL record and
contains all `W` candidate pages. Precomputed item credits, token credits, and
group advantages are deliberately excluded because the actor reconstructs
them from raw critic-member paths using the paper equations.

For page `w` and item `k`, path state `0` masks that item with `L` PAD
tokens while retaining every other item in the generated page. State `l`
reveals the first `l` SID tokens at the same item position. State `L` is the
complete generated page. Repeating this path for all `N` items gives both
item-level and token-level counterfactual credits.

The actor uses the complete-page endpoint for group-relative normalization.
It adds the centered token residual to `A_w/(N*L)`, so all `N*L` token
advantages sum to the original page advantage. The old slot-conditioned
`[W,L]` schema is rejected explicitly and cannot be mixed silently with this
contract.

Every path state must contain at least two critic values. SID values must
already be model vocabulary IDs, including any level-specific TIGER offset.
PAD has token ID `0` by default and cannot appear in a complete item SID.

Validate a produced file before training:

```bash
python3 -m scripts.validate_groups /path/to/groups.jsonl
```

If an environment-specific builder emits one record per complete candidate
page, convert it before validation:

```bash
python3 -m scripts.export_complete_page_groups \
  --input /path/to/page_records.jsonl \
  --output /path/to/groups.jsonl
```

Each page-wise record must provide `group_id`, `input_ids`, `attention_mask`,
`target_tokens` with shape `[N,L]`, and `critic_member_path_values` with shape
`[N,L+1,C]`. The exporter groups pages by `group_id`, orders them by the
optional `candidate_page_index`, and rejects inconsistent contexts, duplicate
pages, and inconsistent complete-page endpoints.

Then run the actor update:

```bash
python3 -m scripts.train_s2tpo_actor \
  --model /path/to/tiger_checkpoint \
  --groups /path/to/groups.jsonl \
  --output-dir outputs/s2tpo_actor \
  --device cuda:0
```

The output contains learner and EMA rollout checkpoints, the run
configuration, and metrics for item telescoping and page-level advantage
conservation. By default, the command uses `beta_q=0.5`, PPO clipping radius
`0.20`, KL coefficient `0.03`, and EMA retention `0.98`. Set
`--advantage-clip` to a positive value only when explicit group-advantage
clipping is desired.

## Critic-session input

`scripts/train_s2tpo_critic.py` consumes `s2tpo_critic_session_v1` JSONL.
Each record contains `context_input_ids`, optional
`context_attention_mask`, one displayed `page_sids` tensor `[N,L]`, its
discounted `session_return`, and non-negative `item_evidence` `[N]`.
The trainer normalizes item evidence into the appendix's alpha weights and
optimizes page, item, prefix, and pairwise-ranking terms. Independent
critic members use Poisson online-bootstrap multiplicities, an equivalent
streaming form of bootstrap resampling.
